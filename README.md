# Floating Code Assistant (Java)

مساعد برمجة عائم يعمل فوق Klencod وأي تطبيق آخر. النسخة الحالية تعمل محليًا دون API وتقدم اقتراحات أولية للأخطاء الشائعة، مع زر نسخ.

## التشغيل في Klencod

أنشئ مشروع Android Java جديدًا، ثم انسخ مجلد `app` وملفات Gradle إلى المشروع. شغّل التطبيق، وافتح صلاحية **الظهور فوق التطبيقات**، ثم اضغط تفعيل المساعد.

لإضافة ذكاء اصطناعي حقيقي لاحقًا، استخدم خادمًا وسيطًا آمنًا؛ لا تضع مفتاح API داخل APK.
